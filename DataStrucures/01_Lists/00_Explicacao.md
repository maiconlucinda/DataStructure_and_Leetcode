# List

## O que seria uma list

Uma sequência de valores em ordem, onde cada valor tem uma posição (índice):

```python
myList = [1, 2, 3, 4, 5, 6, 10]
```

```
índice:  0    1    2    3    4    5    6
        [1]  [2]  [3]  [4]  [5]  [6] [10]
```

## Como funciona

Eu chego no valor pelo índice, e o índice sempre começa no `0`.

A list é **mutável**: depois de criada eu ainda consigo adicionar, remover e trocar valores.

E ela aceita **duplicatas**, por isso faz sentido perguntar quantas vezes um valor aparece (`count`).
